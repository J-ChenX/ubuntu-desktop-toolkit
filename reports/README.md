# 当前发布验证材料

`validation/` 保存 v8 的 UI、拖放、Rust 检查、C 适配层 ASan/UBSan 记录及发布时三机安装核对结果。部署记录是历史证据，当前安装和运行状态请执行 `./desktopctl status`。

`performance/` 保存 v8 的最终测量、v7 比较基线及 Rust/C++ 微基准。旧版数字用于比较，不包含旧版软件包。方法、限制和结论见 [架构与安全](../docs/架构与安全.md)，可维护测试工具在 `tests/performance/`。

测试截图、中间测量、重复工具和已被当前说明替代的早期评估已移除。没有重跑或扩大原始验证范围。

公开版记录已移除主机身份、用户目录、PID 和锁屏状态；测试结果、版本及哈希保持原值。
