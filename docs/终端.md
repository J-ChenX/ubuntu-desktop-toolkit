# Terminator 终端与个人配置

当前来源是本机 Terminator 2.1.1-1。`dpkg -V terminator` 未发现系统包修改；个性化依靠配置文件和主题启动器，不需要维护一份 Terminator 源码分支。

## 已保留设置

- Yaru 暗色 GTK 界面与深色窗口装饰；只作用于该终端启动进程。
- 背景 `#1e1e2e`、前景 `#cdd6f4`，完整 16 色调色板。
- Maple Mono NF CN 11，使用 Regular、Bold、Italic、BoldItalic 四种常用样式；字体按 [下载依赖](下载依赖.md) 准备，仓库只保留许可证与校验值。
- Ctrl+C：有选中文本时复制并清除选区；无选区时保持终端中断命令的功能。使用 Terminator 自带的 smart_copy 逻辑。
- Ctrl+V 粘贴，回滚记录 10000 行；隐藏内部标题栏，分隔条宽度为 3，默认关闭广播输入。
- Ctrl+Alt+T 使用主题启动器；Nautilus 补丁的终端菜单调用同一入口。
- 原有“示例项目启动”自定义菜单保存在 `modules/terminal/config/project-menu.example.conf`。安装时带 `--project-menu` 才加入，路径转换为目标用户主目录，命令不会在安装时运行。

## 安装

先按 [下载依赖](下载依赖.md) 下载字体到指定位置。

```bash
./desktopctl install terminal --check
./desktopctl install terminal
```

默认终端设置和 `~/.config/terminator/config` 会先备份。启动器安装到 `~/.local/bin/terminator-themed`，Python 主题入口安装到 `~/.local/lib/terminator-themed/launch.py`。启动器使用 `$HOME`，不固定用户名。

验证：新开终端检查字体和主题；选一段文本 Ctrl+C、Ctrl+V；无选区执行 `sleep 30` 后 Ctrl+C 应中断；从文件夹菜单打开终端，确认工作目录正确。已有终端窗口无需关闭，但应打开新窗口查看配置效果。

后续调整优先修改配置而非系统 Python 文件。若修改主题启动器或快捷键，验证上述行为后再更新校验清单。完整默认终端行为因 GNOME 版本和其他应用而异，本工具包仅配置 GNOME 默认终端项及个人桌面入口，不修改系统 alternatives。
