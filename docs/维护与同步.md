# 安装、同步、检查和恢复

## 复制到其他电脑

把整个 `ubuntu-desktop-toolkit` 目录复制到目标用户的 `~/code/` 即可。不要只复制安装脚本，也不要把配置里的原用户绝对路径 直接复制给其他用户；工具包启动器使用目标用户 HOME。

统一入口也支持 `./desktopctl sync 用户@主机:code/ubuntu-desktop-toolkit/`，目标目录需先建立；不删除目标额外文件。以下等价 rsync 命令只复制工具包，不安装或重启远端软件：

```bash
ssh user@host 'mkdir -p ~/code/ubuntu-desktop-toolkit'
rsync -av --progress ./ user@host:code/ubuntu-desktop-toolkit/
```

字体和搜狗安装包不随仓库提供；先按 [下载依赖](下载依赖.md) 准备。rsync 会复制本地额外文件（不自动读取 `.gitignore`）；如本地已下载依赖但不想同步，可增加 `--exclude=modules/terminal/fonts/*.ttf --exclude=modules/input-method/packages/*.deb`。

在目标电脑已登录的图形桌面终端执行：

```bash
cd ~/code/ubuntu-desktop-toolkit
./desktopctl install all --check
./desktopctl install all
```

桌面设置按用户保存；不要在 root 会话中执行，不要只通过 SSH 给不正确的 D-Bus 会话设置偏好。安装所有模块后保存工作、注销重登。仅核对文件可在任意终端执行 `sha256sum -c SHA256SUMS`。

## 配置备份和恢复

每次安装在 `~/.local/state/ubuntu-desktop-toolkit/backups/时间戳/` 保存本次将修改的用户文件及 GSettings。先查看清单，再恢复指定备份：

```bash
./desktopctl restore ~/.local/state/ubuntu-desktop-toolkit/backups/实际时间戳
./desktopctl restore ~/.local/state/ubuntu-desktop-toolkit/backups/实际时间戳 --apply
```

恢复会覆盖该次安装管理的配置，之后自己的新改动请另存。它恢复用户配置，不卸载 APT 软件或降级系统包；注销重登后生效。搜狗账号与个人词库不在本工具包中，也不随配置恢复覆盖。

工具包仅保留当前发布版，不再附带旧版软件降级包。配置备份仍独立保存在各电脑用户目录中，不受工具包整理影响。软件降级需要另行取得可信的目标版本及其匹配依赖。

## 文件校验与保存修改

```bash
./desktopctl status
```

验证器报告安装版本和已运行 Nautilus 的哈希；未打开文件管理器时可能没有进程，这不是文件校验失败。同步后先校验再安装。

修改此工具包的配置、文档或安装包后，在审核修改完成后重建根目录校验清单：

```bash
/usr/bin/python3 scripts/update-checksums.py
```

校验清单证明文件在传输中一致，不是软件签名，也不证明未知来源文件可信。完整目录应保存在自己信任的位置。不同功能的实际安装说明分别见文件管理器、终端和搜狗文档。
