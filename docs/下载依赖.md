# 下载第三方依赖

Git 管理代码、配置、说明和校验值；不管理第三方字体或搜狗安装包。下载后放入以下位置，这些路径已由 `.gitignore` 忽略，根目录 `SHA256SUMS` 也不包含下载文件。安装器在任何系统修改之前，按 `external-assets.json` 验证所选模块所需文件；缺少或哈希不符都会停止，包括 `--check`。

## Maple Mono 字体

来源：[Maple Mono 官方发布页](https://github.com/subframe7536/maple-font/releases)。下载 **MapleMono-NF-CN** 字体压缩包，解压后将以下四个文件放入 `modules/terminal/fonts/`，不要将压缩包加入仓库：

- `MapleMono-NF-CN-Regular.ttf`
- `MapleMono-NF-CN-Bold.ttf`
- `MapleMono-NF-CN-Italic.ttf`
- `MapleMono-NF-CN-BoldItalic.ttf`

当前归档字体的内部版本字段为 7.0；未从原始下载记录确认对应的发布标签，因此不把某个标签下载链接当作已验证的同字节来源。下载后以 `external-assets.json` 中四个 SHA256 为当前基线。如果官网下载版本与基线不同，维护者应先验证字体显示和许可证，再更新校验值；不要仅因哈希不同就绕过检查。许可证保留在 `modules/terminal/fonts/LICENSE.txt`。

## 搜狗拼音

打开 [搜狗 Linux 官网](https://shurufa.sogou.com/linux)，选择 x86_64/amd64 的 Debian/Ubuntu 安装包。安装方法参考 [官方指南](https://shurufa.sogou.com/linux/guide)。当前基线为 **4.2.1.145**，保存为：

```text
modules/input-method/packages/sogoupinyin_4.2.1.145_amd64.deb
```

若官网下载已换版，不要重命名新版本伪装为旧版本；先适配验证，再更新 `components.json` 的版本/路径及 `external-assets.json` 的文件名/哈希。

## 准备好后检查

从项目根目录执行：

```bash
./desktopctl check
./desktopctl install all --check
```

第一条校验仓库内容，允许尚未下载依赖；第二条还检查安装需要的下载文件。只安装文件管理器时无需下载字体和搜狗；终端与搜狗分别只要求自己的依赖。Terminator、Fcitx 和 GTK 等系统依赖由安装器通过 Ubuntu APT 仓库获取，不收录其安装包。

本机整理时把既有下载文件移到了 `~/.cache/ubuntu-desktop-toolkit/assets/`，保留相同相对路径；这只是本机缓存，不是新电脑可依赖的下载源。需要复用时：

```bash
cp ~/.cache/ubuntu-desktop-toolkit/assets/modules/terminal/fonts/*.ttf modules/terminal/fonts/
cp ~/.cache/ubuntu-desktop-toolkit/assets/modules/input-method/packages/*.deb modules/input-method/packages/
```

本项目自产的 Nautilus 与 GTK 定制安装包暂时保留：官方上游不提供这些补丁版本，项目也尚无可用的远端 Release 下载地址。它们与完整定制源码属于当前可安装发布所需文件，不能用官方原版包替代。以后发布 Release 资产时可将其从 Git 源码树分离，并记录真实下载地址和校验值。
