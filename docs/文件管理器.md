# 文件管理器：当前已完成的优化与安装

## 当前功能

| 操作 | 安装后的行为 |
|---|---|
| 拖动文件图标、文件名或整项可点击区域 | 拖动文件；空白处才开始框选，支持多文件和跨窗口操作 |
| 拖入浏览器上传/聊天区域 | 提供真实文件，供支持文件拖放的网页接收 |
| Ctrl 拖动 | 复制文件；原移动、撤销和 Escape 取消行为保留 |
| Ctrl+X 剪切 | 文件图标和文字以约 45% 不透明度显示，选中边框保持；剪贴板变更后恢复 |
| 从左向右框选 | 灰色实线矩形，完整包住文件项才选中 |
| 从右向左框选 | 灰色虚线矩形，触碰文件项即可选中 |
| Shift / Ctrl 框选 | 添加选择 / 切换选择；Escape 恢复框选前选择，靠近上下边缘自动滚动 |
| 中键单击文件区空白 | 将其他窗口标签合并到当前窗口；完整路径相同的标签只保留一个，优先保留当前标签 |
| 中键单击标签栏中的某个标签 | 在同一窗口复制该路径为新标签，原有两个标签可变成三个；原标签保留 |
| 拖动标签到窗口外 | 拆分为独立窗口；聚合时保留幸存标签的浏览历史 |
| 点击标签 × | 关闭该标签 |
| 点击当前路径或路径栏空白 | 进入地址编辑；祖先目录仍可点击导航 |
| 双击文件区空白 | 返回上级目录 |
| 慢速单击已选中的文件名 | 重命名；保留原双击打开行为 |
| Ctrl+Shift+C | 复制所选文件路径，多选路径逐行排列；粘贴目标可能自行合并或裁剪换行 |
| “在终端打开” | 调用个人主题 Terminator；安装终端模块后入口可用 |
| GTK3/GTK4 原生文件选择弹窗 | 点击当前路径或路径栏空白进入地址编辑，保留中文路径、父目录导航和保存文件名行为 |

方向框选针对当前启用的实验网格视图。选择样式可独立配置，安装默认保留目标电脑自己的 GTK CSS。路径去重比较完整位置，不按文件夹名称匹配；它也不把不同符号链接路径强制视为同一路径。中键复制会保留重复标签，下一次执行空白区中键聚合才去重。

网页自绘弹窗、Qt 选择器和部分 Snap/Flatpak 沙箱窗口不一定使用宿主 GTK 模块。GTK4 模块只注入 GNOME 文件选择 portal，不设置全局 LD_PRELOAD。

## 安装

在目标电脑的图形桌面终端中，从工具包根目录执行：

```bash
./desktopctl install file-manager --check
./desktopctl install file-manager
```

如需同时复制本机选中样式：

```bash
./desktopctl install file-manager --selection-style
```

之后保存文件和窗口状态，注销并重新登录。脚本不会强制关闭文件管理器：这是为了避免丢失临时搜索页、浏览历史或正在使用的窗口。

安装器完成以下配置：

1. 安装 Nautilus、nautilus-data、libnautilus-extension1a 三件套 `1:42.6-0ubuntu2+localpathbar8`。
2. 安装 `local-gtk-filechooser-click-path 1.0.0`、`local-portal-click-path 1.0.2`。
3. 开启 `org.gnome.nautilus.preferences use-experimental-views`。
4. 向 GTK3 `enabled-gtk-modules` 追加模块名，保留其他模块，并触发 GNOME XSettings 刷新。
5. 写入用户 systemd portal drop-in，设置该服务专用 LD_PRELOAD；重新登录后生效。
6. 如果存在早期个人 Nautilus 启动入口，将其改为 `/usr/bin/nautilus`；备份并停用旧 Python 终端菜单扩展，避免重复菜单。
7. 仅传入 `--selection-style` 时，更新 GTK CSS 中本工具包管理的选中样式区块，保留其他 CSS。

## 安装后核对

```bash
./desktopctl status
gsettings get org.gnome.nautilus.preferences use-experimental-views
gsettings get org.gnome.settings-daemon.plugins.xsettings enabled-gtk-modules
systemctl --user show xdg-desktop-portal-gnome.service -p Environment -p MainPID
```

实际试用：两个不同目录标签，中键复制其中一个变成三个；中键单击空白合并后重复路径回到一个；灰色框选左右方向规则不同；剪切文件应变淡；文件能拖入另一个文件夹以及浏览器支持的上传区。

## 已验证范围和归档

v8 发布时已核对 三台验证电脑的安装文件一致；这是发布验证记录，不代表当前运行状态。安装与实际进程版本通过 `./desktopctl status` 核对。v8 的 15 项 UI 检查和 10 项拖放检查通过；另完成 ASan/UBSan 适配层检查。旧版曾验证导航、重命名与两类弹窗，相关回归脚本仍保留。v8 未重跑完整上游套件，记录集中在 `reports/validation/`。

当前五件套安装包和清单位于 `modules/file-manager/release/`，其中 `source/nautilus-localpathbar8.tar.xz` 是完整源码。`src/nautilus-patches/local-rust-selection.patch` 是 Rust 核心与缓存适配增量补丁；更早路径栏等改动已在完整源码中。`src/gtk3-chooser/` 与 `src/gtk4-chooser/` 提供两个模块的源码、打包脚本及测试程序，构建需要匹配版本的 GTK 开发依赖。文件管理器回归脚本集中在 `tests/file-manager/`。源码用于维护，普通安装只需预编译包。
