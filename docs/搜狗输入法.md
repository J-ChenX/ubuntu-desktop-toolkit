# 搜狗输入法安装：Ubuntu 22.04 amd64

当前安装基线为 `sogoupinyin_4.2.1.145_amd64.deb`，安装包不纳入仓库。先按 [下载依赖](下载依赖.md) 从官网下载并放到指定位置。此包与 **Fcitx 4** 配合。

来源：[搜狗 Linux 官方首页](https://shurufa.sogou.com/linux)、[官方安装指南](https://shurufa.sogou.com/linux/guide)。官网是动态页面；以下步骤结合本机包依赖和现有配置整理，不是逐字转载。

## 推荐安装方法

```bash
cd ~/code/ubuntu-desktop-toolkit
./desktopctl install sogou --check
./desktopctl install sogou
```

脚本安装 Fcitx 4、GTK/Qt 所需依赖、简体中文语言包和搜狗软件包；执行 `im-config -n fcitx`，配置当前用户登录环境及 Fcitx 自启动。不会删除 IBus、Fcitx5 或已有个人词库。

然后保存工作，注销并重新登录。在“语言支持”中确认键盘输入法系统是 `fcitx`；打开 `fcitx-config-gtk3`，在输入法列表加入“搜狗拼音”。找不到时取消“只显示当前语言”。保留键盘输入项，按配置中的切换键切换中文/英文，并在文本编辑器、浏览器和终端分别测试。

当前可复现基线是 Xorg 会话。若 Wayland 下某些应用无法输入，可在登录页选择“Ubuntu on Xorg”后重试；不需要修改全局 GDM 配置强制所有用户切换。

## 手动安装等价步骤

```bash
sudo apt update
sudo apt install fcitx fcitx-config-gtk im-config language-pack-zh-hans \
  libqt5qml5 libqt5quick5 libqt5quickwidgets5 qml-module-qtquick2 libgsettings-qt1 \
  ./modules/input-method/packages/sogoupinyin_4.2.1.145_amd64.deb
im-config -n fcitx
```

在自己的 `~/.profile` 中确认以下设置（已有相同设置不必重复添加）：

```sh
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
```

注销重登；若桌面没有自动启动 Fcitx，可运行 `fcitx`，并在启动应用中添加同一命令。

## 排查

- `im-config -m`：确认选中的输入法框架；输出含 fcitx5 名称不等于正在运行 Fcitx5。
- `pgrep -a fcitx`：检查实际进程。避免多个输入法框架同时抢占；优先调整会话设置，不直接批量卸载桌面组件。
- `fcitx-diagnose`：在目标图形会话中运行诊断。报告可能包含环境路径，分享前检查。
- 能输入英文但无中文：检查搜狗是否加入 Fcitx 列表、Qt 依赖是否安装、是否已经注销重登。
- 仅浏览器不工作：先验证原生文本编辑器，再核对该浏览器的 X11/Wayland 与沙箱输入法支持。

软件包保留搜狗原许可。安装包仅在本地按需下载，不表示获取了重新许可或公开分发权。更新时从官网选择正确架构，先在目标 Ubuntu 版本验证，再更新 `external-assets.json` 校验值、`components.json` 版本和相关说明。
